# กติกา Puzzle Engine (ฉบับร่าง)

ไฟล์นี้คือกติกาที่ engine ทำตาม ถ้ากติกาเปลี่ยน ให้แก้ไฟล์นี้ก่อนแก้โค้ด

## สัญญาณ
- **สวิตช์พื้น (ToggleSignal)** เป็นทอกเกิล
  - มีตัวแรกเข้ามาบนสวิตช์ตอนที่ไม่มีใครอยู่ → สลับสถานะ 1 ครั้ง
  - ตัวที่เข้ามาเพิ่มตอนมีคนอยู่แล้ว ไม่สลับ
  - ตัวที่ออก ไม่สลับ
  - นับต่อ "ตัว" ไม่ใช่ต่อ collider
- **ตัวที่กดสวิตช์ได้**
  - แมว: กดได้ ยกเว้นตอนบิน
  - กล่อง: กดได้
  - ก้อนขน: กดได้ ทั้งตอนบินและตอนนอน

## เกต (Gate)
- `All` = ทุกตัวต้อง ON
- `Any` = อย่างน้อยหนึ่งตัว ON
- ไม่มีสัญญาณเลย = ปิด

## ประตู (Door)
- เปิดเมื่อ `Gate(All, สวิตช์ของประตู)` เป็นจริง ปิดเมื่อเป็นเท็จ
- ค่าเริ่มต้น `All` (ทุกตัว ON = เปิด)
- ประตูไม่สลับเองตามจำนวนครั้งที่กด

## สายพาน (ConveyorBelt)
- ทำงานตราบที่ `Gate(All, สวิตช์ของสายพาน)` เป็นจริง
- ไม่มีสวิตช์ = ทำงานตลอด

## ปุ่มส่งยา (ลำดับยา)
ช่องพักยา 3 ช่อง ไล่ตามลำดับ 1 → 3
- ช่องว่าง → ข้ามไปเลย ไม่มีการรอหรือหน่วงเพิ่ม
- ยาชิ้นแรกที่มี → ปล่อยทันที
- ยาชิ้นถัดไป → รอให้ชิ้นก่อนหน้า "ติด" แล้วรออีก **3 วินาที** จึงปล่อย
- "ติด" = สัตว์ทำความสามารถเสร็จแล้ว (นิยามต่อชนิดยาในโค้ดของสัตว์)
- ถ้าไม่ติดภายใน 20 วินาที ถือว่าติดแล้ว (กันลำดับค้าง)
- กดซ้ำระหว่างลำดับกำลังทำงาน ไม่มีผล

## เงื่อนไขชนะ (LevelGoal)
- นิยามเป็นเงื่อนไขต่อด่าน เช่น "ประตู A เปิด"
- เมื่อจริงครั้งแรกจะจบด่าน และจบแล้วจะไม่กลับไปยังไม่จบ
- *(ยังไม่กำหนดกติกาของแต่ละด่าน)*

## ยืนยันแล้ว
1. ประตูเปิดเมื่อสวิตช์ตามเงื่อนไขเป็นจริง (ค่าเริ่มต้นทุกตัว ON = เปิด)
2. สวิตช์บนพื้นเป็นทอกเกิล ส่วนปุ่มส่งยาคือปุ่มจาก StagingSlot ไม่ใช่สวิตช์บนพื้น
3. ยาชิ้นถัดไป รอ 3 วินาที นับหลังยาชิ้นก่อนหน้าติดแล้ว
4. สายพานทำงานตาม Gate เหมือนประตู

## ข้อที่ยังค้างในโค้ด
- ลบ latch ของสายพาน (`stayOnOnceActivated`) แล้ว สายพาน `wall (1)` ใน Game Play Test จะทำงานตามสวิตช์เหมือนประตู ค่าเก่าที่ค้างในไฟล์ฉากจะหายไปเองเมื่อเซฟฉากใน Unity
- ระบบ dropper เดิม (ช่อง `PotionSlot` ที่คลิกทดสอบได้) ถูกลบออกจาก `PotionSequenceDropper` แล้ว ไฟล์ `PotionSlot.cs` ยังอยู่แต่ไม่มีโค้ดเรียกใช้ ยังไม่ลบเพราะฉากมี component นี้อยู่
- ตอนกดส่งยา ช่องพักจะถูกล้างทันที ผู้เล่นจึงไม่เห็นยาค้างในช่องระหว่างลำดับ (ปรับภาพทีหลังได้)
